# Catalogue Grimoire V1

## Pourquoi ce document existe

Ce document recense les applications officiellement proposées par Grimoire V1.

L'objectif n'est pas de lister toutes les applications disponibles sous Linux.

L'objectif est de proposer une sélection cohérente, maintenable et documentable.

Chaque choix doit pouvoir être :

* recommandé
* expliqué
* documenté
* maintenu

Grimoire recommande.

Grimoire n'impose pas.

## Philosophie de sélection

Grimoire ne considère pas qu'un utilisateur doit nécessairement choisir une seule application par catégorie.

Certaines catégories sont naturellement exclusives :

* Shell principal
* Navigateur principal

D'autres peuvent être cumulées afin de construire un workflow adapté aux besoins de chacun :

* Terminaux
* Gestionnaires de fichiers
* Éditeurs
* Outils Git
* Applications IA

Par exemple :

* Ghostty + Kitty
* Thunar + Yazi
* Lazygit + Git CLI
* KeePassXC + Bitwarden

sont des combinaisons parfaitement valides.

L'objectif de Grimoire n'est pas de limiter les choix de l'utilisateur, mais de proposer un cadre cohérent lui permettant de construire progressivement son propre environnement.

# Philosophie du catalogue

Le catalogue Grimoire n'a pas vocation à devenir exhaustif.

Chaque nouvelle application ajoutée augmente :

* la maintenance
* la documentation
* les tests
* la complexité du projet

Pour cette raison, Grimoire privilégie un nombre réduit de choix clairement expliqués.

L'objectif n'est pas d'offrir toutes les possibilités.

L'objectif est d'offrir des choix cohérents et compréhensibles.

---

# Règle d'évolution

Une application ne doit être ajoutée au catalogue que si :

* elle est activement maintenue ;
* elle apporte une valeur réelle ;
* elle peut être documentée correctement ;
* elle s'intègre à la philosophie Grimoire.

Le catalogue doit rester volontairement limité afin de préserver la qualité de l'expérience utilisateur.

Lorsqu'une catégorie le permet, le cumul d'applications complémentaires doit être privilégié à une logique de choix exclusif.
