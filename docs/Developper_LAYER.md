# Developer Layer

## Pourquoi ce document existe

Le Developer Layer regroupe les outils destinés aux développeurs.

Il est indépendant des profils utilisateur.

Un utilisateur peut être :

* Débutant + Developer Layer
* Avancé + Developer Layer
* Personnalisé + Developer Layer

---

# Philosophie

Le Developer Layer ne doit pas imposer de technologies.

Il propose des ensembles cohérents adaptés à différents usages.

# Ce qui n'appartient pas au Developer Layer

## Containers

Les technologies de conteneurisation sont gérées par un Layer séparé.

Exemples :

* Docker
* Podman

---

## Virtualisation

Les technologies de virtualisation sont gérées par un Layer séparé.

Exemples :

* Virt-Manager
* GNOME Boxes

---

# Objectif

Permettre à chaque utilisateur de disposer rapidement d'un environnement de développement cohérent sans imposer un langage ou une technologie particulière.
