# Profils utilisateur Grimoire

## Pourquoi ce document existe

Les profils permettent de simplifier l'installation de Grimoire en adaptant le niveau de personnalisation proposé à l'utilisateur.

Chaque profil représente une expérience différente.

L'objectif n'est pas de limiter les choix.

L'objectif est d'adapter le nombre de choix au niveau de confort de l'utilisateur.

---

# Philosophie

Les profils décrivent l'expérience utilisateur.

Ils ne décrivent pas les capacités techniques de la machine.

Les fonctionnalités avancées sont gérées par les Layers.

---

# Profil Débutant

## Public cible

Utilisateur Linux découvrant Hyprland.

## Objectif

Permettre une installation rapide sans connaissance préalable de l'écosystème Hyprland.

## Principe

Utilisation exclusive des recommandations Grimoire.

## Questions posées

Aucune ou strict minimum.

## Applications recommandées

* Ghostty
* Fish
* Brave
* Thunar
* Yazi
* OnlyOffice
* VLC
* KeePassXC
* Obsidian
* Vesktop

## Expérience

Installer.

Découvrir.

Apprendre.

---

# Profil Avancé

## Public cible

Utilisateur Linux souhaitant construire rapidement son environnement.

## Objectif

Permettre quelques choix importants sans exposer l'ensemble du catalogue.

## Questions posées

* Terminal
* Navigateur
* Éditeur
* Gestionnaire de fichiers graphique
* Suite bureautique

## Principe

Les choix les plus impactants sont laissés à l'utilisateur.

Le reste repose sur les recommandations Grimoire.

---

# Profil Personnalisé

## Public cible

Utilisateur souhaitant contrôler l'ensemble de son installation.

## Objectif

Permettre un accès complet au catalogue Grimoire.

## Questions posées

Toutes les catégories disponibles.

## Principe

L'utilisateur construit son environnement à partir du catalogue complet.

---

# Base commune

Installée dans tous les profils.

## Outils système

## Desktop Core

* Hyprland
* Waybar

# Layers

Les Layers sont indépendants du profil utilisateur.

Ils ajoutent des capacités supplémentaires.

Exemples :

* Developer Layer
* Container Layer
* Virtualization Layer
* Homelab Layer (plus tard)
